本政策說明適用於 iPhone、iPad 和 Android 的遊戲 Deep Lantern（以下稱“本應用”“我們”）收集什麼、為什麼收集、誰會收到、儲存多久，以及你可以如何刪除。聯絡方式：deeplanterngame@gmail.com。

簡要說明

無需註冊，也無需登入：我們從不詢問你的電子電子郵件信箱、真實姓名或密碼。一個隨機裝置 ID 會讓遊戲在我們的伺服器上擁有一個匿名帳號，用於備份你的進度、保護你的珍珠和角色，以及執行排行榜。崩潰報告、遊戲分析、廣告和購買會經過下面列出的服務。我們從不記錄你輸入的內容。你可以在遊戲內刪除所有資料（設定 → 支援 → 刪除我的資料）。

我們收集什麼以及為什麼

匿名帳號（裝置 ID）

首次啟動時，本應用會建立一個隨機裝置 ID（iOS 上為 identifier for vendor；Android 上為 Android ID 或隨機 UUID），並儲存在手機的安全儲存中。該 ID 會傳送到我們的伺服器（託管於 Supabase），伺服器只儲存用金鑰生成的雜湊值，絕不儲存 ID 本身，並將其關聯到一個匿名使用者 ID。同時我們會儲存基本裝置資訊：平臺、系統版本、裝置型號和品牌、應用版本和構建號、語言、螢幕尺寸，以及它是真機還是模擬器。讓你保持登入的會話儲存在手機的安全儲存（Keychain / Keystore）中。
原因：在不索取個人資訊的情況下，為你的安裝提供一個帳號。

你的遊戲：進度備份、珍珠和購買

你的進度——紀錄、統計和徽章、戰役星星、任務進度、教程步驟、你自己的單字列表、Polyglot 複習卡片以及最近 50 次下潛——儲存在手機上，並備份到我們的伺服器。你的珍珠（餘額以及獲得和花費的記錄）、角色、能力和購買所解鎖的內容記錄在我們的伺服器上，你領取的每日獎勵、任務和禮物也記錄在那裡。
原因：讓重新安裝後一切都能恢復，並讓珍珠和道具不會丟失或被偽造。

下潛

每次下潛結束時，會向我們的伺服器傳送一份摘要：模式及其設定、得分、深度、時長、輸入正確和失誤的字母、打字速度、獎勵、使用的能力、是否使用了第二次機會，以及下潛的時間特徵——按鍵之間的間隔分別落在各個時間段的次數，以及每個區域的總計。其中絕不包含你按了哪些鍵或輸入了什麼。
原因：為下潛發放珍珠、保持排行榜公平並發現作弊。

潛水員名稱、頭像、國家/地區和排行榜

你選擇的潛水員名稱、你選作頭像的潛艇以及一個國家/地區（手機的地區，或你在排行榜中選擇的國家/地區）會傳送到我們的伺服器，並在排行榜上你的最佳成績旁顯示給其他玩家。名字會經過詞語過濾。如果不想被看到，請不要使用真實姓名。我們還會儲存你所在時區與 UTC 的時差（而不是你的位置），以便遊戲知道你的一天何時開始，用於每日獎勵和連續記錄。

反饋和舉報

如果你在評分視窗中寫了留言，星級和內容會傳送給我們。如果你在排行榜上舉報其他玩家，對方的匿名 ID 和原因會傳送給我們。如果你給我們寄電子郵件，我們會收到你的電子郵件地址和留言，並且只用於回覆你。

註冊時的裝置驗證

建立新帳號時，本應用會請求 Apple App Attest 或 Google Play Integrity 確認這是在真實裝置上執行的正版遊戲；我們的伺服器會將結果與你的裝置記錄一起儲存。註冊請求來源網路地址的單向雜湊會被短暫儲存，用於限制同一網路可建立的帳號數量。
原因：防止虛假帳號刷取獎勵和佔滿排行榜。

崩潰報告和效能（Sentry）

當本應用崩潰或出錯時，會向 Sentry 傳送一份報告：錯誤及其堆疊資訊、裝置型號、系統和應用版本、你當時所在的介面、最近應用內操作的簡短記錄（例如“下潛開始”“商店已開啟”）以及匿名使用者 ID。會抽取一小部分介面切換用於效能測量。我們不會把你的 IP 地址作為個人資料傳送，也不會附加姓名或電子郵件信箱。
原因：發現並修復錯誤。

使用事件

本應用會記錄遊戲中發生的事情——開啟的介面、開始和結束的下潛及其模式和得分、發起的購買、領取的獎勵、更改的設定——並附上匿名使用者 ID。它們作為 Sentry 崩潰報告中的“記錄”傳送，只包含 ID 和數字，不包含個人資訊。
原因：瞭解遊戲的哪些部分運作良好，並修復問題。

遊戲分析（GameAnalytics）

遊戲玩法的摘要會傳送到 GameAnalytics：開始、完成或失敗的下潛（模式、戰役關卡、到達的深度、得分）、獲得和花費的珍珠、購買（商品、價格和幣種）、觀看或無法展示的廣告、教程步驟、評分請求以及設定更改。GameAnalytics 還會收集裝置和使用資料（型號、系統和應用版本、語言和國家/地區、會話開始時間和時長）以及一個裝置 ID：廣告 ID（iOS 上為 IDFA，Android 上為廣告 ID）僅在應用可用時收集——在 iPhone 上僅當你在 Apple 的提示中允許跟蹤時——否則使用應用專屬 ID（iOS 上為 identifier for vendor，Android 上為 app set ID）。在廣告同意步驟之前不會傳送任何內容。在適用 GDPR 的地區（歐洲經濟區、英國、瑞士），只有當你在 Google 的同意表單中同意在裝置上儲存和訪問資訊、衡量內容效果以及 GameAnalytics 作為供應商時，GameAnalytics 才會啟動；如果你在 設定 → 廣告隱私選項中撤回該同意，傳送就會停止。它絕不會收到你的潛水員名稱、我們的匿名使用者 ID、電子郵件信箱或真實姓名，也不會按每次按鍵傳送事件。
原因：瞭解下潛在哪裡變得過難、玩家使用哪些獎勵和優惠，並平衡遊戲。

廣告（Google AdMob）

免費版會展示獎勵影片（僅在你選擇觀看時）以及下潛之間的簡短全屏廣告——從不展示橫幅廣告，從不在下潛過程中展示，也從不在面向小玩家的見習生模式中展示。廣告由 Google AdMob 提供，在獲得允許時它會收到你裝置的廣告 ID（iOS 上為 IDFA，Android 上為廣告 ID）、IP 地址、裝置資訊以及你與廣告的互動。在 iPhone 上，本應用會先進行說明，然後顯示 Apple 的“App 跟蹤透明度”提示；如果你不允許跟蹤，AdMob 不會獲得 IDFA，並展示非個性化廣告。在歐洲經濟區、英國和瑞士，Google 的同意表單（UMP）會先詢問你的選擇，你可以隨時在 設定 → 廣告隱私選項中更改。當獎勵影片發放獎勵時，Google 會用你的匿名使用者 ID 向我們的伺服器確認。購買移除廣告、艦長禮包或 Lantern+ 會關閉全屏廣告。
原因：廣告讓遊戲保持免費。

購買（Apple、Google、RevenueCat）

付款完全由 App Store 或 Google Play 處理；我們從不會看到你的銀行卡或付款資訊。RevenueCat 會核驗你的收據，並透過匿名使用者 ID 告知本應用和我們的伺服器你擁有什麼。它會收到你的購買記錄（商品、日期、價格、商店所在國家/地區）、應用使用者 ID 和裝置資訊。
原因：解鎖你購買的內容、發放珍珠禮包，並在新手機上恢復購買。

通知

提醒（例如“你的每日獎勵已準備好”）只在你允許之後才在手機本地安排。沒有推播伺服器，也不收集推播令牌。

只儲存在手機上的內容

你的設定（聲音、振動、語言、難度、輔助功能）、通知偏好和記錄、廣告和評分計數器，以及最近 50 次之外的下潛記錄，絕不會離開你的手機。

我們不收集的內容

不收集電子電子郵件地址（除非你給我們寫信）、電話號碼、真實姓名、通訊錄、照片、麥克風、精確位置、帳號登入或你在遊戲中輸入的內容。我們不出售個人資料。

法律依據

在適用 GDPR、《個人資料保護法》或類似法律的地區，我們處理你的資料是為了提供你所要求的遊戲（帳號、進度備份、珍珠、購買和排行榜），是基於我們保持遊戲安全公平和修復錯誤的正當利益（下潛核查、裝置驗證、崩潰報告、使用事件），而個性化廣告和遊戲分析則基於你的同意。你可以隨時撤回同意，這不影響撤回之前已進行的處理。

儲存期限

你的帳號、進度備份、珍珠記錄、角色、排行榜成績、反饋和舉報會一直儲存，直到你刪除資料或要求我們刪除。下潛摘要會在 30 天后刪除；排行榜上只保留它們創下的最佳成績。為防止有排名的 Daily 被重玩，你裝置的單向雜湊以及它是否已使用今天的 Daily 機會最多儲存 48 小時，即使在你刪除資料之後也是如此。為防止在同一部手機上用新帳號再次領取一次性獎勵，該裝置雜湊還會與它已領取的每個一次性獎勵的名稱一起儲存，不含你的帳號，也不含任何日期：Fener 導覽獎勵和商店的一次性優惠在遊戲營運期間一直儲存，首次下潛獎勵和每日寶箱儲存到其當天之後兩天。裝置驗證結果會隨你的資料一起刪除（被拒絕的註冊儲存 90 天），網路地址雜湊在 2 天后刪除。Sentry 最多儲存崩潰報告 90 天。 GameAnalytics 按其自身政策儲存分析資料。RevenueCat、Apple 和 Google 會在法律及其政策要求的期限內儲存購買記錄（例如用於稅務和退款）。電子郵件在回覆所需的期限內儲存。手機上的資料會一直保留，直到你刪除它或解除安裝本應用。

刪除你的資料

在遊戲中：設定 → 支援 → 刪除我的資料。確認後，你的帳號及其記錄會立即從我們的伺服器刪除，手機上儲存的所有內容（進度、珍珠、用珍珠買的角色、潛水員名稱、下潛記錄、設定）都會被清除，遊戲從頭開始。用真錢購買的項目仍保留在你的 Apple 或 Google 帳號中，可透過恢復購買找回。你也可以寫信至 deeplanterngame@gmail.com；我們會在 30 天內回覆。已傳送到 Sentry 的崩潰報告會在 90 天內自動失效。

你的權利

根據你所在的地區（例如依據 GDPR、UK GDPR、KVKK、LGPD、PIPA、APPI、《個人資料保護法》或美國各州法律），你可以要求訪問、更正、刪除或匯出你的資料，反對或限制其使用，並撤回同意。廣告同意可在遊戲中（設定 → 廣告隱私選項）或手機的跟蹤設定中更改。其他事項請寫信給我們；你也可以向所在地的資料保護機構投訴。

兒童

Deep Lantern 不面向 13 歲以下兒童，我們也不會在知情的情況下收集他們的個人資料。面向小玩家的見習生模式完全不展示廣告。如果你認為有 13 歲以下兒童向我們提供了個人資料，請聯絡我們，我們會將其刪除。

變更

如果本政策有變更，我們會更新本頁面及其日期；重要變更也會在遊戲內通知。
