Deep Lantern 是一款適用於 iPhone、iPad 和 Android 的打字遊戲。你駕駛一艘鮟鱇魚潛艇潛入深海，輸入迎面而來的海洋生物所帶的單字，把它們攔下：有練速度、練專注、學新語言和放鬆的各種模式，支援 15 種輸入語言。

聯絡我們

問題、錯誤、購買、想法——都可以寫信給我們，我們會盡快回覆：

deeplanterngame@gmail.com

遊戲內：設定 → 支援 → 聯絡我們。請附上你的支援代碼 （可在同一處複製）、手機型號以及當時在做什麼。

常見問題

我買的東西不見了，怎麼找回？

用真錢購買的項目（移除廣告、艦長禮包、 Lantern+）屬於你的 Apple ID 或 Google 帳號。請用購買時的同一個 Apple ID 或 Google 帳號登入，開啟遊戲裡的 商店，滑到最底部，點按恢復購買。

如何取消 Lantern+？

Lantern+ 是由應用程式商店管理的按月或按年訂閱。iPhone 和 iPad：設定 → 你的名字 → 訂閱。Android：Google Play → 你的個人資料 → 付款和訂閱 → 訂閱。請至少在當前週期結束前 24 小時取消，以免續訂；在週期結束前仍可繼續使用。

重新安裝遊戲後進度還在嗎？

在。你的進度、珍珠和角色儲存在手機上，並備份到我們伺服器上的一個匿名帳號裡，所以在同一部手機上重新安裝就能找回。目前還不能轉移到新手機；用真錢購買的項目在任何手機上都可以透過恢復購買找回。

如何刪除我的資料？

在遊戲中開啟設定 → 支援 → 刪除我的資料並確認。這會刪除你在我們伺服器上的帳號以及手機上的所有內容——進度、珍珠、用珍珠買的角色、潛水員名稱和下潛記錄——遊戲會從頭開始。用真錢購買的項目仍保留在你的 Apple 或 Google 帳號中，可透過恢復購買找回。你也可以寄電子郵件給我們，由我們替你刪除。詳情見隱私政策。

通知：遊戲會傳送什麼？怎麼關閉？

所有通知都在你的手機上安排（沒有推播伺服器）：每天最多一條，不會在你的安靜時段傳送，並且只在你允許之後才傳送。可在遊戲的 設定 → 通知中更改，或在手機設定裡關閉 Deep Lantern 的通知。

沒有聲音。

即使手機處於靜音模式，遊戲也會播放聲音，所以請先檢查遊戲內的設定：設定 → 音效與回饋中的音效和音樂滑桿，以及暫停介面上的快速靜音按鈕。然後再檢查手機音量。

可以離線玩嗎？

可以。所有模式都能離線遊玩；你獲得的珍珠和進度會在重新聯網後傳送到我們的伺服器。排行榜、廣告和購買需要聯網。
