Deep Lantern 是一款适用于 iPhone、iPad 和 Android 的打字游戏。你驾驶一艘鮟鱇鱼潜艇潜入深海，输入迎面而来的海洋生物所带的单词，把它们拦下：有练速度、练专注、学新语言和放松的各种模式，支持 15 种输入语言。

联系我们

问题、错误、购买、想法——都可以写信给我们，我们会尽快回复：

deeplanterngame@gmail.com

游戏内：设置 → 支持 → 联系我们。请附上你的支持代码 （可在同一处复制）、手机型号以及当时在做什么。

常见问题

我买的东西不见了，怎么找回？

用真钱购买的项目（去除广告、船长礼包、 Lantern+）属于你的 Apple ID 或 Google 账号。请用购买时的同一个 Apple ID 或 Google 账号登录，打开游戏里的 商店，滑到最底部，点按恢复购买。

如何取消 Lantern+？

Lantern+ 是由应用商店管理的按月或按年订阅。iPhone 和 iPad：设置 → 你的名字 → 订阅。Android：Google Play → 你的个人资料 → 付款和订阅 → 订阅。请至少在当前周期结束前 24 小时取消，以免续订；在周期结束前仍可继续使用。

重新安装游戏后进度还在吗？

在。你的进度、珍珠和角色保存在手机上，并备份到我们服务器上的一个匿名账号里，所以在同一部手机上重新安装就能找回。目前还不能转移到新手机；用真钱购买的项目在任何手机上都可以通过恢复购买找回。

如何删除我的数据？

在游戏中打开设置 → 支持 → 删除我的数据并确认。这会删除你在我们服务器上的账号以及手机上的所有内容——进度、珍珠、用珍珠买的角色、潜水员名字和下潜记录——游戏会从头开始。用真钱购买的项目仍保留在你的 Apple 或 Google 账号中，可通过恢复购买找回。你也可以发邮件给我们，由我们替你删除。详情见隐私政策。

通知：游戏会发送什么？怎么关闭？

所有通知都在你的手机上安排（没有推送服务器）：每天最多一条，不会在你的安静时段发送，并且只在你允许之后才发送。可在游戏的 设置 → 通知中更改，或在手机设置里关闭 Deep Lantern 的通知。

没有声音。

即使手机处于静音模式，游戏也会播放声音，所以请先检查游戏内的设置：设置 → 音效与反馈中的音效和音乐滑块，以及暂停界面上的快速静音按钮。然后再检查手机音量。

可以离线玩吗？

可以。所有模式都能离线游玩；你获得的珍珠和进度会在重新联网后发送到我们的服务器。排行榜、广告和购买需要联网。
