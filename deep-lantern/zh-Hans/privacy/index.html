本政策说明适用于 iPhone、iPad 和 Android 的游戏 Deep Lantern（以下称“本应用”“我们”）收集什么、为什么收集、谁会收到、保存多久，以及你可以如何删除。联系方式：deeplanterngame@gmail.com。

简要说明

无需注册，也无需登录：我们从不询问你的电子邮箱、真实姓名或密码。一个随机设备 ID 会让游戏在我们的服务器上拥有一个匿名账号，用于备份你的进度、保护你的珍珠和角色，以及运行排行榜。崩溃报告、游戏分析、广告和购买会经过下面列出的服务。我们从不记录你输入的内容。你可以在游戏内删除所有数据（设置 → 支持 → 删除我的数据）。

我们收集什么以及为什么

匿名账号（设备 ID）

首次启动时，本应用会创建一个随机设备 ID（iOS 上为 identifier for vendor；Android 上为 Android ID 或随机 UUID），并保存在手机的安全存储中。该 ID 会发送到我们的服务器（托管于 Supabase），服务器只保存用密钥生成的哈希值，绝不保存 ID 本身，并将其关联到一个匿名用户 ID。同时我们会保存基本设备信息：平台、系统版本、设备型号和品牌、应用版本和构建号、语言、屏幕尺寸，以及它是真机还是模拟器。让你保持登录的会话保存在手机的安全存储（Keychain / Keystore）中。
原因：在不索取个人信息的情况下，为你的安装提供一个账号。

你的游戏：进度备份、珍珠和购买

你的进度——纪录、统计和徽章、战役星星、任务进度、教程步骤、你自己的单词列表、Polyglot 复习卡片以及最近 50 次下潜——保存在手机上，并备份到我们的服务器。你的珍珠（余额以及获得和花费的记录）、角色、能力和购买所解锁的内容记录在我们的服务器上，你领取的每日奖励、任务和礼物也记录在那里。
原因：让重新安装后一切都能恢复，并让珍珠和道具不会丢失或被伪造。

下潜

每次下潜结束时，会向我们的服务器发送一份摘要：模式及其设置、得分、深度、时长、输入正确和失误的字母、打字速度、奖励、使用的能力、是否使用了第二次机会，以及下潜的时间特征——按键之间的间隔分别落在各个时间段的次数，以及每个区域的总计。其中绝不包含你按了哪些键或输入了什么。
原因：为下潜发放珍珠、保持排行榜公平并发现作弊。

潜水员名字、头像、国家/地区和排行榜

你选择的潜水员名字、你选作头像的潜艇以及一个国家/地区（手机的地区，或你在排行榜中选择的国家/地区）会发送到我们的服务器，并在排行榜上你的最佳成绩旁显示给其他玩家。名字会经过词语过滤。如果不想被看到，请不要使用真实姓名。我们还会保存你所在时区与 UTC 的时差（而不是你的位置），以便游戏知道你的一天何时开始，用于每日奖励和连续记录。

反馈和举报

如果你在评分窗口中写了留言，星级和内容会发送给我们。如果你在排行榜上举报其他玩家，对方的匿名 ID 和原因会发送给我们。如果你给我们发邮件，我们会收到你的邮箱地址和留言，并且只用于回复你。

注册时的设备验证

创建新账号时，本应用会请求 Apple App Attest 或 Google Play Integrity 确认这是在真实设备上运行的正版游戏；我们的服务器会将结果与你的设备记录一起保存。注册请求来源网络地址的单向哈希会被短暂保存，用于限制同一网络可创建的账号数量。
原因：防止虚假账号刷取奖励和占满排行榜。

崩溃报告和性能（Sentry）

当本应用崩溃或出错时，会向 Sentry 发送一份报告：错误及其堆栈信息、设备型号、系统和应用版本、你当时所在的界面、最近应用内操作的简短记录（例如“下潜开始”“商店已打开”）以及匿名用户 ID。会抽取一小部分界面切换用于性能测量。我们不会把你的 IP 地址作为个人数据发送，也不会附加姓名或邮箱。
原因：发现并修复错误。

使用事件

本应用会记录游戏中发生的事情——打开的界面、开始和结束的下潜及其模式和得分、发起的购买、领取的奖励、更改的设置——并附上匿名用户 ID。它们作为 Sentry 崩溃报告中的“记录”发送，只包含 ID 和数字，不包含个人信息。
原因：了解游戏的哪些部分运作良好，并修复问题。

游戏分析（GameAnalytics）

游戏玩法的摘要会发送到 GameAnalytics：开始、完成或失败的下潜（模式、战役关卡、到达的深度、得分）、获得和花费的珍珠、购买（商品、价格和币种）、观看或无法展示的广告、教程步骤、评分请求以及设置更改。GameAnalytics 还会收集设备和使用数据（型号、系统和应用版本、语言和国家/地区、会话开始时间和时长）以及一个设备 ID：广告 ID（iOS 上为 IDFA，Android 上为广告 ID）仅在应用可用时收集——在 iPhone 上仅当你在 Apple 的提示中允许跟踪时——否则使用应用专属 ID（iOS 上为 identifier for vendor，Android 上为 app set ID）。在广告同意步骤之前不会发送任何内容。在适用 GDPR 的地区（欧洲经济区、英国、瑞士），只有当你在 Google 的同意表单中同意在设备上存储和访问信息、衡量内容效果以及 GameAnalytics 作为供应商时，GameAnalytics 才会启动；如果你在 设置 → 广告隐私选项中撤回该同意，发送就会停止。它绝不会收到你的潜水员名字、我们的匿名用户 ID、邮箱或真实姓名，也不会按每次按键发送事件。
原因：了解下潜在哪里变得过难、玩家使用哪些奖励和优惠，并平衡游戏。

广告（Google AdMob）

免费版会展示激励视频（仅在你选择观看时）以及下潜之间的简短全屏广告——从不展示横幅广告，从不在下潜过程中展示，也从不在面向小玩家的小学员模式中展示。广告由 Google AdMob 提供，在获得允许时它会收到你设备的广告 ID（iOS 上为 IDFA，Android 上为广告 ID）、IP 地址、设备信息以及你与广告的互动。在 iPhone 上，本应用会先进行说明，然后显示 Apple 的“App 跟踪透明度”提示；如果你不允许跟踪，AdMob 不会获得 IDFA，并展示非个性化广告。在欧洲经济区、英国和瑞士，Google 的同意表单（UMP）会先询问你的选择，你可以随时在 设置 → 广告隐私选项中更改。当激励视频发放奖励时，Google 会用你的匿名用户 ID 向我们的服务器确认。购买去除广告、船长礼包或 Lantern+ 会关闭全屏广告。
原因：广告让游戏保持免费。

购买（Apple、Google、RevenueCat）

付款完全由 App Store 或 Google Play 处理；我们从不会看到你的银行卡或付款信息。RevenueCat 会核验你的收据，并通过匿名用户 ID 告知本应用和我们的服务器你拥有什么。它会收到你的购买记录（商品、日期、价格、商店所在国家/地区）、应用用户 ID 和设备信息。
原因：解锁你购买的内容、发放珍珠礼包，并在新手机上恢复购买。

通知

提醒（例如“你的每日奖励已准备好”）只在你允许之后才在手机本地安排。没有推送服务器，也不收集推送令牌。

只保存在手机上的内容

你的设置（声音、振动、语言、难度、辅助功能）、通知偏好和记录、广告和评分计数器，以及最近 50 次之外的下潜记录，绝不会离开你的手机。

我们不收集的内容

不收集电子邮箱地址（除非你给我们写信）、电话号码、真实姓名、通讯录、照片、麦克风、精确位置、账号登录或你在游戏中输入的内容。我们不出售个人数据。

法律依据

在适用 GDPR、《个人信息保护法》或类似法律的地区，我们处理你的数据是为了提供你所要求的游戏（账号、进度备份、珍珠、购买和排行榜），是基于我们保持游戏安全公平和修复错误的正当利益（下潜核查、设备验证、崩溃报告、使用事件），而个性化广告和游戏分析则基于你的同意。你可以随时撤回同意，这不影响撤回之前已进行的处理。

保存期限

你的账号、进度备份、珍珠记录、角色、排行榜成绩、反馈和举报会一直保存，直到你删除数据或要求我们删除。下潜摘要会在 30 天后删除；排行榜上只保留它们创下的最佳成绩。为防止有排名的 Daily 被重玩，你设备的单向哈希以及它是否已使用今天的 Daily 机会最多保存 48 小时，即使在你删除数据之后也是如此。为防止在同一部手机上用新账号再次领取一次性奖励，该设备哈希还会与它已领取的每个一次性奖励的名称一起保存，不含你的账号，也不含任何日期：Fener 导览奖励和商店的一次性优惠在游戏运营期间一直保存，首次下潜奖励和每日宝箱保存到其当天之后两天。设备验证结果会随你的数据一起删除（被拒绝的注册保存 90 天），网络地址哈希在 2 天后删除。Sentry 最多保存崩溃报告 90 天。 GameAnalytics 按其自身政策保存分析数据。RevenueCat、Apple 和 Google 会在法律及其政策要求的期限内保存购买记录（例如用于税务和退款）。邮件在回复所需的期限内保存。手机上的数据会一直保留，直到你删除它或卸载本应用。

删除你的数据

在游戏中：设置 → 支持 → 删除我的数据。确认后，你的账号及其记录会立即从我们的服务器删除，手机上保存的所有内容（进度、珍珠、用珍珠买的角色、潜水员名字、下潜记录、设置）都会被清除，游戏从头开始。用真钱购买的项目仍保留在你的 Apple 或 Google 账号中，可通过恢复购买找回。你也可以写信至 deeplanterngame@gmail.com；我们会在 30 天内回复。已发送到 Sentry 的崩溃报告会在 90 天内自动失效。

你的权利

根据你所在的地区（例如依据 GDPR、UK GDPR、KVKK、LGPD、PIPA、APPI、《个人信息保护法》或美国各州法律），你可以要求访问、更正、删除或导出你的数据，反对或限制其使用，并撤回同意。广告同意可在游戏中（设置 → 广告隐私选项）或手机的跟踪设置中更改。其他事项请写信给我们；你也可以向所在地的数据保护机构投诉。

儿童

Deep Lantern 不面向 13 岁以下儿童，我们也不会在知情的情况下收集他们的个人数据。面向小玩家的小学员模式完全不展示广告。如果你认为有 13 岁以下儿童向我们提供了个人数据，请联系我们，我们会将其删除。

变更

如果本政策有变更，我们会更新本页面及其日期；重要变更也会在游戏内通知。
