このポリシーは、iPhone・iPad・Android 向けゲーム Deep Lantern（以下「本アプリ」「当方」）が何を収集し、なぜ、誰が受け取り、どれだけの期間保存し、どのように削除できるかを説明します。連絡先：deeplanterngame@gmail.com

概要

会員登録もログインもありません。メールアドレス、本名、パスワードを求めることは一切ありません。ランダムな端末 ID によってゲームには当方サーバー上の匿名アカウントが作られ、進行状況のバックアップ、真珠とキャラクターの保護、ランキングの運営に使われます。クラッシュレポート、ゲーム分析、広告、購入は下記のサービスを通ります。入力した内容を記録することはありません。すべてゲーム内から削除できます（設定 → サポート → データを削除）。

収集する情報とその理由

匿名アカウント（端末 ID）

初回起動時、本アプリはランダムな端末 ID（iOS では identifier for vendor、Android では Android ID またはランダムな UUID）を作成し、端末の安全な保存領域に保管します。この ID は当方サーバー（Supabase 上）に送られますが、サーバーには秘密鍵で作ったハッシュだけを保存し、ID そのものは保存せず、匿名のユーザー ID に結びつけます。あわせて、プラットフォーム、OS バージョン、機種とメーカー、アプリのバージョンとビルド、言語、画面サイズ、実機かシミュレーターかといった基本的な端末情報を保存します。サインイン状態を保つセッションは端末の安全な保存領域（Keychain / Keystore）に保管されます。
理由：個人情報をうかがわずに、インストールごとにアカウントを用意するためです。

あなたのゲーム：進行状況のバックアップ、真珠、購入

進行状況（記録、統計とバッジ、キャンペーンの星、クエストの進み具合、チュートリアルの段階、自作の単語リスト、Polyglot の復習カード、直近 50 回のダイブ）は端末に保存され、当方サーバーにバックアップされます。真珠（残高と、獲得・使用の履歴）、キャラクター、アビリティ、購入によって解放されたものは当方サーバーで管理され、受け取ったデイリー報酬、クエスト、プレゼントもそこに記録されます。
理由：再インストールですべてが戻るように、また真珠やアイテムが消えたり偽造されたりしないようにするためです。

ダイブ

ダイブが終わると、その概要が当方サーバーに送られます：モードと設定、スコア、深さ、時間、入力できた文字とミスした文字、入力速度、ボーナス、使ったアビリティ、セカンドチャンスを使ったかどうか、そしてダイブのタイミングの特徴（キーを押す間隔が各時間帯にいくつ入ったかと、各ゾーンの合計）です。どのキーを押したか、何を入力したかは一切含まれません。
理由：ダイブの真珠を支払い、ランキングを公平に保ち、不正を見つけるためです。

ダイバー名、プロフィール画像、国、ランキング

選んだダイバー名、プロフィール画像として選んだ潜水艦、国（端末の地域、またはランキングで選んだ国）は当方サーバーに送られ、ランキングであなたのベストスコアの横に他のプレイヤーへ表示されます。名前は単語フィルターを通ります。見られたくない場合は本名を使わないでください。また、デイリー報酬や連続記録のために一日の始まりを判断できるよう、UTC からのタイムゾーンの差（位置情報ではありません）を保存します。

フィードバックと通報

評価画面でメモを書くと、星の数と本文が当方に送られます。ランキングで他のプレイヤーを通報すると、その人の匿名 ID と理由が当方に送られます。メールをいただいた場合は、メールアドレスとメッセージを受け取り、お返事のためにだけ使います。

登録時の端末チェック

新しいアカウントを作るとき、本アプリは Apple App Attest または Google Play Integrity に、実機上の正規のゲームであることの確認を依頼します。当方サーバーはその結果を端末の記録とともに保存します。登録元のネットワークアドレスの一方向ハッシュを短期間保管し、 1 つのネットワークで作れるアカウント数を制限します。
理由：偽アカウントが報酬を集めたりランキングを埋め尽くしたりするのを防ぐためです。

クラッシュレポートとパフォーマンス（Sentry）

本アプリがクラッシュしたりエラーが起きたりすると、Sentry にレポートが送られます：エラーとスタックトレース、機種、OS とアプリのバージョン、表示中の画面、直前のアプリ内操作の短い記録（例：「ダイブ開始」「ストアを開いた」）、匿名ユーザー ID。画面遷移の一部をパフォーマンス計測に使います。IP アドレスを個人データとして送ることはなく、名前やメールアドレスも添付しません。
理由：不具合を見つけて直すためです。

利用イベント

本アプリはゲーム内の出来事（開いた画面、モードとスコア付きのダイブの開始と終了、開始した購入、受け取った報酬、変更した設定）を匿名ユーザー ID とともに記録します。これらは Sentry のクラッシュレポート内の「記録」として送られ、ID と数値だけを含み、個人情報は含みません。
理由：ゲームのどこがうまく機能しているかを把握し、問題を直すためです。

ゲーム分析（GameAnalytics）

ゲームの遊ばれ方の概要が GameAnalytics に送られます：開始・クリア・失敗したダイブ（モード、キャンペーンのレベル、到達した深さ、スコア）、獲得・使用した真珠、購入（商品、価格、通貨）、視聴した広告や表示できなかった広告、チュートリアルの段階、評価の依頼、設定の変更です。GameAnalytics は端末と利用のデータ（機種、OS とアプリのバージョン、言語と国、セッションの開始時刻と長さ）と端末 ID も収集します：広告 ID（iOS では IDFA、Android では広告 ID）はアプリが利用できる場合のみ（iPhone では Apple の確認でトラッキングを許可した場合のみ）、それ以外はアプリ固有の ID（iOS では identifier for vendor、Android では app set ID）です。広告の同意の手順より前に送られるものはありません。GDPR が適用される地域（EEA、英国、スイス）では、Google の同意フォームで、端末への情報の保存とアクセス、コンテンツのパフォーマンス測定、ベンダーとしての GameAnalytics に同意した場合にのみ GameAnalytics が動作します。 設定 → 広告のプライバシー設定 で同意を取り消すと送信は止まります。ダイバー名、当方の匿名ユーザー ID、メールアドレス、本名が送られることはなく、キー入力ごとのイベントも送られません。
理由：どこでダイブが難しくなりすぎるか、どの報酬やオファーが使われているかを知り、ゲームのバランスを調整するためです。

広告（Google AdMob）

無料版では、リワード動画（自分で見ると選んだときだけ）と、ダイブとダイブの間の短い全画面広告を表示します。バナー広告はなく、ダイブ中や小さなプレイヤー向けの 見習い モードでは表示しません。広告は Google AdMob が配信し、許可されている場合は端末の広告 ID（iOS では IDFA、Android では広告 ID）、IP アドレス、端末情報、広告への反応を受け取ります。iPhone では、本アプリがまず説明し、そのあと Apple の App Tracking Transparency の確認を表示します。トラッキングを許可しない場合、AdMob は IDFA を受け取らず、パーソナライズされていない広告を表示します。EEA、英国、スイスでは、まず Google の同意フォーム（UMP）が選択をうかがい、設定 → 広告のプライバシー設定 でいつでも変更できます。リワード動画で報酬が支払われると、Google はあなたの匿名ユーザー ID とともに当方サーバーにそれを確認します。広告を削除、 キャプテンパック、Lantern+ を購入すると全画面広告はオフになります。
理由：広告によってゲームを無料で提供できるからです。

購入（Apple、Google、RevenueCat）

支払いはすべて App Store または Google Play が処理し、当方がカードや支払い情報を目にすることはありません。RevenueCat はレシートを確認し、匿名ユーザー ID を使って、あなたが何を持っているかを本アプリと当方サーバーに伝えます。RevenueCat は購入履歴（商品、日付、価格、ストアの国）、アプリのユーザー ID、端末情報を受け取ります。
理由：購入したものを解放し、真珠パックを付与し、新しい端末で購入を復元するためです。

通知

リマインダー（例：「デイリー報酬の準備ができました」）は、許可をいただいたあとにだけ、端末上で予約されます。プッシュサーバーはなく、プッシュトークンも収集しません。

端末だけに残るもの

設定（サウンド、振動、言語、難易度、アクセシビリティ）、通知の設定と履歴、広告と評価のカウンター、直近 50 回より前のダイブ履歴は、端末の外に出ることはありません。

収集しないもの

メールアドレス（メールをいただいた場合を除く）、電話番号、本名、連絡先、写真、マイク、正確な位置情報、アカウントのログイン、ゲームで入力した内容は収集しません。個人データを販売することはありません。

法的根拠

GDPR や同様の法律が適用される場合、当方は、あなたが求めたゲームを提供するため（アカウント、進行状況のバックアップ、真珠、購入、ランキング）、ゲームを安全かつ公平に保ち不具合を直すという正当な利益のため（ダイブの確認、端末チェック、クラッシュレポート、利用イベント）、そしてパーソナライズ広告とゲーム分析についてはあなたの同意に基づいて、データを取り扱います。同意はいつでも取り消せ、それ以前の取り扱いには影響しません。

保存期間

アカウント、進行状況のバックアップ、真珠の履歴、キャラクター、ランキングのスコア、フィードバック、通報は、データを削除するか削除を依頼されるまで保存します。ダイブの概要は 30 日後に削除され、ランキングにはそれらが出したベストスコアだけが残ります。ランキング対象の Daily をやり直せないよう、端末の一方向ハッシュと、その端末が今日の Daily を使ったかどうかを最長 48 時間保存します（データを削除したあとも同様です）。同じ端末で新しいアカウントを作って一度きりの報酬を再び受け取れないよう、その端末ハッシュを、すでに受け取った一度きりの報酬の名前とともに、アカウントや日付なしで保存します：Fener のツアーボーナスとストアの一度きりのオファーはゲームが続く限り、初ダイブボーナスとデイリーチェストはその日の 2 日後まで。端末チェックの結果はデータとともに削除され（拒否された登録は 90 日保存）、ネットワークアドレスのハッシュは 2 日後に削除されます。Sentry はクラッシュレポートを最長 90 日保存します。GameAnalytics は分析データを自社のポリシーに従って保存します。RevenueCat、Apple、Google は、法律と各社のポリシーで求められる期間（税務や返金のためなど）購入記録を保存します。メールは返信に必要な期間保存します。端末内のデータは、削除するかアプリをアンインストールするまで残ります。

データの削除

ゲーム内：設定 → サポート → データを削除。確認すると、アカウントとその記録は当方サーバーからすぐに削除され、端末に保存されたもの（進行状況、真珠、真珠で買ったキャラクター、ダイバー名、ダイブ履歴、設定）はすべて消去され、ゲームは最初から始まります。現金での購入は Apple または Google のアカウントに残り、 購入を復元 で戻せます。deeplanterngame@gmail.com にご連絡いただくこともできます。30 日以内にお返事します。すでに Sentry に送られたクラッシュレポートは 90 日以内に自動的に削除されます。

あなたの権利

お住まいの地域によっては（例：GDPR、UK GDPR、KVKK、LGPD、PIPA、個人情報保護法（APPI）、米国の州法）、データの開示、訂正、削除、エクスポートを求めたり、利用に異議を述べたり制限したり、同意を取り消したりできます。広告の同意はゲーム内（設定 → 広告のプライバシー設定）または端末のトラッキング設定で変更できます。その他のことはご連絡ください。お住まいの地域のデータ保護機関（日本では個人情報保護委員会）に申し立てることもできます。

お子さま

Deep Lantern は 13 歳未満のお子さまを対象としておらず、意図してその個人データを収集することはありません。小さなプレイヤー向けの 見習い モードでは広告を一切表示しません。13 歳未満のお子さまが当方に個人データを提供したと思われる場合は、ご連絡いただければ削除します。

変更

このポリシーを変更する場合は、このページと日付を更新します。重要な変更はゲーム内でもお知らせします。
